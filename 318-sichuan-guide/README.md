# 318 川西 · 自驾攻略网站

一个静态网页旅行攻略，记录成都出发、沿318国道穿越川西高原、抵达稻城亚丁的7天6晚情侣自驾路线。

## 预览

用浏览器直接打开 `index.html` 即可，无需任何构建工具或服务器。

也可部署到 GitHub Pages，访问地址为：  
`https://<你的用户名>.github.io/318-sichuan-guide/`

## 目录结构

```
318-sichuan-guide/
├── index.html       # 主页面
├── css/
│   └── style.css    # 所有样式
├── js/
│   └── main.js      # 交互脚本（导航高亮、滚动动画）
└── README.md
```

## 路线概览

| 天数 | 路段 | 里程 |
|------|------|------|
| Day 1 | 成都 → 泸定 → 康定 | ~350km |
| Day 2 | 康定 → 折多山 → 塔公 → 新都桥 | ~120km |
| Day 3 | 新都桥 → 雅江 → 卡子拉山 → 理塘 | ~220km |
| Day 4 | 理塘 → 桑堆红草地 → 稻城 → 亚丁 | ~185km |
| Day 5 | 亚丁景区全天深度游 | — |
| Day 6 | 亚丁 → 稻城 → 理塘 → 新都桥（返程） | ~320km |
| Day 7 | 新都桥 → 康定 → 成都 | ~400km |

**全程约 1600km，建议5月–10月出发，9–10月秋色最佳。**

## 部署到 GitHub Pages

1. 将本仓库 Push 到 GitHub
2. 进入仓库 → Settings → Pages
3. Source 选择 `main` 分支，根目录 `/`
4. 保存后等待1–2分钟，即可通过上方链接访问

## 技术栈

- 纯 HTML / CSS / JavaScript，无任何依赖
- 字体：Google Fonts（Noto Serif SC + Noto Sans SC）
- 响应式布局，支持手机端浏览
