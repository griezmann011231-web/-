# 发布成永久网站

推荐用 GitHub Pages，免费、稳定，适合这个静态网页。

## 方法一：网页上传

1. 打开 https://github.com/new
2. Repository name 填：`fudan-nursing-308-study-site`
3. 选择 Public。
4. 创建仓库后，点击 `uploading an existing file`。
5. 上传这个文件夹里的所有内容：
   - `index.html`
   - `styles.css`
   - `app.js`
   - `.nojekyll`
   - `assets` 文件夹
6. 上传完成后，进入仓库的 `Settings`。
7. 左侧点 `Pages`。
8. Source 选择 `Deploy from a branch`。
9. Branch 选择 `main`，文件夹选择 `/root`，然后保存。
10. 等 1-3 分钟，页面会显示网址，通常是：
    `https://你的用户名.github.io/fudan-nursing-308-study-site/`

## 注意

- 这个网站是公开的，任何拿到链接的人都能看。
- 如果之后修改内容，重新上传覆盖文件即可。
- 进度勾选和错题本保存在浏览器本地，不会同步到网站服务器。
