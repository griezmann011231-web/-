# 上传到 GitHub Pages

如果你要把这个护理学考研公共英语网站也放到同一个 GitHub 仓库：

1. 打开仓库页面。
2. 点击 `Add file` 或 `Upload files`。
3. 上传整个 `fudan-nursing-english-site` 文件夹。
4. 等 GitHub Pages 自动部署完成。
5. 访问：
   `https://griezmann011231-web.github.io/-/fudan-nursing-english-site/`

如果你想让网址更短，就只上传本文件夹里面的内容，不要套 `fudan-nursing-english-site` 这一层文件夹。
