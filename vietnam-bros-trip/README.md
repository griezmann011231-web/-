# 兄弟懂你行

越南兄弟旅行静态网站，包含前期准备、9 天路线、景点美食、按摩店和预算估算。

## 文件

- `index.html`：网站页面
- `styles.css`：页面样式
- `script.js`：清单、筛选、预算交互
- `preview-top.png`：网站预览图

## GitHub Pages 发布

1. 新建一个 GitHub 仓库。
2. 把这个文件夹里的所有文件上传到仓库根目录。
3. 进入仓库 `Settings` -> `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，文件夹选择 `/root`。
6. 保存后等待 GitHub 生成访问链接。
